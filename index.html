ABOUT THE PLUGIN

LED Test Pattern

LED 测试图生成器

当前版本
V1.4
作者
Disguise 张岳
适用环境
Designer r32+ 插件框架
图片输出
PNG · 当前项目 objects/VideoFile
文件名包含屏幕名称与分辨率，重名自动加序号。

主要功能

五种配色模式：双色棋盘格、整屏渐变、箱体内渐变、自定义图片、多色棋盘格。支持箱体坐标、双角 PNG Logo，以及独立控制的屏幕名称、分辨率和米制尺寸。
